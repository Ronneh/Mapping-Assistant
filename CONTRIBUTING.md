# Contribution Policy

Mapping Assistant is a proprietary project maintained by authorized project
owners. External contributions are not accepted.

Do not submit pull requests, patches, forks, issue-based feature proposals, or
other unsolicited code changes. Do not redistribute the source code or publish
derivative versions.

Internal changes must follow `AGENTS.md` and the project owner's instructions.
Third-party libraries and historical content remain subject to their own
licenses and are not covered by this policy.
